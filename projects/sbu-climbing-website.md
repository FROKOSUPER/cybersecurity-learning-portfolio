# SBU Climbing Club Website

## Project Overview

I contributed to the SBU Climbing Club website through a private GitHub repository. Since the codebase is private, this page describes my work without sharing source code or internal project details.

## What I Worked On

- Updated an outdated link to the club's page on SB Engaged
- Helped fix issues involving rides, events, the gallery, and form validation
- Worked on a page hydration issue
- Submitted changes through GitHub pull requests

## What I Learned

This was my first time contributing to an existing codebase instead of starting a project from scratch. I had to read code written by other people, understand how different parts of the site worked together, and make focused changes without breaking unrelated features.

I also gained experience with the pull request workflow. Each change had to be clearly described and organized so that another contributor could review it.

## Skills Practiced

- Reading and navigating an unfamiliar codebase
- Debugging existing website behavior
- Making focused fixes instead of rewriting working code
- Using branches and pull requests
- Describing technical changes for reviewers
- Collaborating on a shared project
