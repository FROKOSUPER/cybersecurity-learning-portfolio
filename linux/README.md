# Linux Learning

Linux is central to cybersecurity because servers, security tools, cloud systems, and embedded devices commonly rely on it. This section records practical exercises that build confidence with the command line and develop a methodical approach to investigating files and systems.

## Labs

| Lab | Main concepts | Status |
| --- | --- | --- |
| [File Analysis and Layered Data](bandit-file-analysis.md) | Hexdumps, redirection, file signatures, gzip, bzip2, tar | Complete |

## Commands Practiced

| Command | Purpose |
| --- | --- |
| `mkdir` | Create a directory |
| `cp` | Copy a file |
| `cd` | Change the current directory |
| `ls` | List directory contents |
| `xxd -r` | Reverse a hexdump into its original bytes |
| `file` | Identify data by examining its contents |
| `mv` | Rename or move a file |
| `gunzip` | Decompress gzip data |
| `bzip2 -d` | Decompress bzip2 data |
| `tar -xf` | Extract a tar archive |

## Approach

For each exercise, I document the objective, concepts, reasoning process, mistakes, security relevance, and possible next steps. Challenge secrets and exact solutions are intentionally excluded.
